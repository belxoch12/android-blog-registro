## Funcionalidades

- Formulario de registro con nombre, correo, teléfono, contraseña y confirmación de contraseña.
- Diseño con Material Components y ConstraintLayout.
- Incluye la dependencia Volley, lista para conectar el formulario a una API.

## Estructura

```
app/src/main/java/com/example/blogapp_2practica/
├── MainActivity.kt   # Actividad principal
└── Register.kt       # Actividad del formulario de registro
```

## Tecnologías

Kotlin · Android SDK (min 24, target 33) · Material Components · ConstraintLayout · Volley

## Cómo ejecutarlo

1. Clona el repositorio y ábrelo en **Android Studio**.
2. Espera a que Gradle sincronice las dependencias.
3. Ejecútalo en un emulador o dispositivo físico.
